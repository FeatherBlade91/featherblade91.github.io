相册管理

上传的照片会直接提交到 GitHub 仓库，几分钟后线上相册自动更新

本地相册（离线管理，不用联网）

选定项目文件夹后，自动列出 photos/ 里的全部照片： 新照片标记为「待登记」，JPG 自动读取 EXIF 拍摄日期。 日期和标题都可以留空，留空的词条在相册里不会显示。 需要 Chrome / Edge，且本地用 python -m http.server 方式打开本页。

① 连接仓库（上传到线上）

本地运行 python3 tools/local_server.py 后，管理端会自动读取当前电脑的 GitHub CLI 登录凭据，不需要手动粘贴 Token。

② 上传新照片

③ 管理现有照片

左右方向键切换照片 · F2 编辑名称 · Tab 到日期 · Ctrl/⌘+S 保存
